# 🚀 Noxy Store

Noxy Store is a next-generation futuristic eCommerce mobile shop website built using pure HTML, CSS, and JavaScript.  
Designed with premium UI/UX, cinematic animations, glassmorphism effects, and responsive layouts, this project delivers a modern online shopping experience inspired by Apple, Samsung, Tesla, and AI-powered platforms.

---

# ✨ Features

- 📱 Ultra Premium Mobile Store UI
- 🌙 Dark & Light Mode Toggle
- ⚡ Smooth Animations & Transitions
- 💎 Glassmorphism Design
- 🛒 Product Showcase Sections
- 🔍 Search & Filter UI
- ❤️ Wishlist & Cart Design
- 📲 Fully Responsive Layout
- 🚀 Fast Loading Performance
- 🎨 Modern Gradient Effects
- 🔥 SEO Optimized Structure
- 🧠 AI Inspired Interface
- 📦 Product Cards & Categories
- 💻 Cross Browser Compatible
